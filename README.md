# Movie-Recommendation-System
A Movie Recommendation System built using Python and Machine Learning. It uses Content-Based Filtering, CountVectorizer, and Cosine Similarity to recommend similar movies based on genres, keywords, cast, crew, and movie overview.
Movie Recommendation System
About the Project
This project is a Movie Recommendation System developed using Python and Machine Learning.
It recommends similar movies using Content-Based Filtering.
Technologies Used

Python
NumPy
Pandas
NLTK
Scikit-learn
CountVectorizer
Cosine Similarity

Features

Movie data preprocessing
Genre and keyword extraction
Cast and director extraction
Text stemming
Movie similarity calculation
Top 5 movie recommendations

credits.csv
